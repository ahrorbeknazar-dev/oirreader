Olympus OIR Inspector

Opens Olympus FV-series .oir confocal files directly in the browser — metadata, per-channel intensity statistics and a quick nuclei count. Files are read on this computer and never uploaded.

Drop an .oir file anywhere on this page

The whole file is parsed locally. A 1024×1024, three-channel field takes about a second.
